Hygge

Et lille programmeringssprog på dansk. Skriv kode med ord som sæt, hvis og gentag, og se den køre med det samme.

Din kode

Linje 1, tegn 1 

        
      

    

    
Ctrl + Enter kører programmet · Tab rykker ind · Tryk Esc og så Tab for at forlade editoren

  


  

    

      

        
        
        
      

      
    


    

      

      

        

        
Papiret går fra −200 til 200 på begge leder. Hvert tern er 20 skridt.

      

    


    

      
Det første, Hygge gør, er at dele din kode op i tokens: nøgleord, navne, tal, tekster og tegn. Det er sådan, computeren begynder at læse.

      

    


    

      
Bagefter bygger Hygge et syntakstræ af dine tokens. Træet viser, hvilke dele der hører sammen, fx at 2 + 3 * 4 betyder 2 + (3 * 4). Fortolkeren kører programmet ved at gå træet igennem.

      

    

  






  
Håndbog

  
Alt, hvad Hygge kan, på én side. Hver kommando står på sin egen linje, og blokke står mellem { og }.


  

    

      
Skriv noget

      
skriv viser tekst og tal. Kommaer sætter mellemrum mellem værdierne.

      
skriv "Hej verden!"
skriv "2 + 2 =", 2 + 2

    

    

      
Variabler

      
En variabel er en kasse med et navn. sæt lægger en værdi i kassen.

      
sæt navn = "Ida"
sæt point = 10
sæt point += 5     # nu er point 15

    

    

      
Regning

      
+ - * / som du kender dem. % giver resten ved division, og ^ opløfter. Decimaltal skrives med punktum.

      
skriv 17 % 5     # 2
skriv 2 ^ 8      # 256
skriv 3.5 * 2    # 7

    

    

      
Tekst

      
Tekst står i anførselstegn. Med + sætter du tekster sammen.

      
sæt hilsen = "Hej " + navn
skriv længde(hilsen)
skriv "ha" * 3   # hahaha

    

    

      
Sammenligning

      
= betyder "er lig med", og != betyder "er forskellig fra". Kombinér med og, eller og ikke. Svaret er sandt eller falsk.

      
skriv 3 < 5           # sandt
skriv alder >= 13 og ikke træt

    

    

      
Hvis og ellers

      
Programmet vælger, hvilken blok der skal køres.

      
hvis point > 100 {
    skriv "Ny rekord!"
} ellers hvis point > 50 {
    skriv "Godt gået"
} ellers {
    skriv "Prøv igen"
}

    

    

      
Gentag

      
Den letteste løkke. Den kører blokken et bestemt antal gange.

      
gentag 3 gange {
    skriv "Hurra!"
}

    

    

      
For-løkker

      
Tæller fra et tal til et andet. Med trin bestemmer du, hvor store skridt der tages.

      
for i fra 1 til 5 {
    skriv i * i
}
for i fra 10 til 0 trin -2 {
    skriv i
}

    

    

      
Mens

      
Kører, så længe betingelsen er sand. stop hopper ud af løkken, og fortsæt springer til næste runde.

      
sæt liv = 3
mens liv > 0 {
    skriv "Liv tilbage:", liv
    sæt liv -= 1
}

    

    

      
Lister

      
En liste gemmer flere værdier. Pladserne tælles fra 0, og -1 er den sidste.

      
sæt frugter = ["æble", "pære"]
tilføj(frugter, "banan")
skriv frugter[0], frugter[-1]
for hver frugt i frugter {
    skriv frugt
}

    

    

      
Funktioner

      
En funktion er en opskrift, du kan bruge igen. returner giver et svar tilbage.

      
funktion hils(navn) {
    returner "Hej " + navn + "!"
}
skriv hils("Malik")

    

    

      
Spørg brugeren

      
spørg venter på et svar. Svaret er tekst, så brug tal(...), hvis du vil regne med det.

      
sæt navn = spørg("Hvad hedder du?")
sæt alder = tal(spørg("Hvor gammel er du?"))
skriv navn, "fylder", alder + 1, "næste år"

    

    

      
Tegn med skildpadden

      
Skildpadden starter midt på papiret i (0, 0) og kigger opad. Den tegner, når den går.

      
farve("blå")
gentag 4 gange {
    fremad(100)
    drej_højre(90)
}

    

    

      
Kommentarer

      
Alt efter # er en note til dig selv. Hygge springer det over.

      
# Dette er en kommentar
skriv "Dette bliver vist"   # og dette er også en kommentar

    

  


  

    
Indbyggede funktioner

    
Funktioner, der følger med Hygge. Du kalder dem med parenteser, fx længde(liste).

    

  


  

    
Sådan virker Hygge indeni

    
Hygge er skrevet i JavaScript i filen hygge.js. Den arbejder i tre trin, ligesom rigtige programmeringssprog som Python og JavaScript gør.

    
    
      
  1. 
        
    Lexeren deler koden op
    
        
    Koden bliver delt op i tokens: ord, tal, tekster og tegn. Se dem under fanen .
    
      
    2. 
      
  2. 
        
    Parseren bygger et træ
    
        
    Tokens bliver sat sammen til et syntakstræ, der viser, hvad der hører sammen. Se det under .
    
      
    3. 
      
  3. 
        
    Fortolkeren kører træet
    
        
    Fortolkeren går træet igennem fra toppen og udfører hver del. Hver kommando er et skridt, og antallet af skridt står ved resultatet.
